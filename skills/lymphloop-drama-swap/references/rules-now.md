# 现行规则（换品设计、提示词与全链路门禁）

本文件汇总当前 **Antigravity 原生看听 + 100x `100x-minimax-h3`（`standard` / `768P` / `9:16`）** 链路的全部生效规则。凡与历史旧版冲突处，一律以本文件为准。

---

## 1. 模型、渠道与原生运行模式

- **默认视频生成**：**100x 渠道 `100x-minimax-h3`（`standard` / `768P` / `9:16`）**，首次原片参考生成与人物卡补做统一默认使用；时长取目标段向上取整整数秒（4–15），全部走接口参数，**绝不写进提示词正文**。
- **显式备选（仅用户点名时使用）**：`LYMPHLOOP_X100_MODEL=100x-seedance-2.0`（`720P`）或 `LYMPHLOOP_GEN_CHANNEL=apimart`（APIMART `seedance-2.0` / `720p`）。**禁用 `100x-seedance-2.5`**。
- **零外部 Gemini 原生模式**：`agent_native.is_native() == True` 默认生效。识别、筛查、观察、审片、闪回复核、产品帧板核查均由当前 Agent 直接用 `read_file` 看图看片听音完成，本地听写用 `faster-whisper`。

## 2. 对白改词优先“音节数对齐”

- **适用场景**：**画内可见说话人嘴部**的改词（`on_screen_dialogue`）。
- **核心原则**：视频参考生成会强烈跟随 `@视频1` 原说话人的口型开合节拍；新旧词音节差过大极易导致吞音、卡顿或口型僵硬。
- **规范**：
  1. 品牌名：原词为 4 音节（如 `Lymphoria`）且画内见嘴时，优先改为 **4 音节的 `Yesnap LymphLoop`**；画外旁白可自由用 `LymphLoop`。
  2. 成分与用法词：尽量挑选音节数差 ≤ 1 的等效词（如 4 音节 `Stillingia` 配 `Dandelion` / `Calendula` / `Echinacea`；2 音节 `dropper` 配 `packet`）。
  3. 自动校验：`swap.py generate --prepare-only` 自动运行 `agent_native.check_dialogue_syllables()`，音节差过大时在终端提醒。
  4. 若首轮仍因原口型锚定导致念错或发僵，第二轮直接走**人物卡模式 + `# voice:`**，彻底脱离原视频口型束缚。

## 3. 换品规则表（`scripts/swap_design.py`）

- **分工**：Agent 只通过 `read_file` 观察镜头客观事实（竞品是什么、在哪、占画面多大、手在做什么、是否为主体），导入 `RUN/design/obs/`；**换成什么形态、传哪几张图、动作照原片还是重设计，一律由规则表 `decide()` 决定**，写入 `RUN/plan/swap_design.json`。
- **按顺序匹配，第一条命中即定**（“很小”= 高度 < 画面 1/15；“人手边”= 有手碰或在一手长以内）：

| 规则 | 原片事实 | 换成 | 动作 | 说明 |
|---|---|---|---|---|
| **R0** | 筛查确认有实体竞品（`competitor_visible=yes` 或 `overrides` 标 `visual`），观察未看清 | 手捏已开封条包 | 重新设计 | 远景小物件防漏换；无实体竞品（成分动画/标题卡）在 `overrides.json` 写 `"physical_competitor": false` 跳过 |
| **S1** | 手机或电脑屏幕显示竞品购物页/落地页（`on_screen` 或 override `"screen": "phone"/"computer"`） | 整页换我方商品页（手机 `phone_page`、电脑 `desktop_page`）；屏幕外实物照常换 | 重新设计 | 屏幕图与实物图一并传 |
| **R0c** | R0 镜头且同段相邻最近产品镜头是手持纸盒/条包 | 沿用同一件产品与同一套图 | 重新设计 | 前一镜优先于后一镜，防同段频繁变形 |
| **R7d** | R7 镜头（小而近人）且片中前后 2 个镜头内有纸盒 | 统一为手里握着的同一个纸盒 | 重新设计 | 防同场对话里盒与条包来回跳变 |
| **R5d** | 手持纸盒镜头且前后 2 镜内有从口袋掏出/收进口袋 | 统一为手捏未开封条包沿手持镜传导 | 重新设计 | 口袋装不下纸盒；按全片镜头顺序跨段算 |
| **R5b** | 从手提包拿出且同段下一镜为纸盒 | 统一为拿纸盒 | 照原片 | 手提包装得下纸盒，保持连贯 |
| **R1** | 服用（放嘴里、喝、往嘴里滴） | 已开封条包 | 嘴唇含住开口吸 | 服用一律只有单手闭唇轻抿一种动作 |
| **R2** | 抽滴管、用滴管、看得清的滴管 | 有手：原拿瓶手捏未开封条包；无手且瓶立台面：原位立 1 纸盒；仅单根滴管无手无瓶：桌面平放 1 未开条包特写 | 重新设计 | 滴管出现即穿帮，且避免平放条包自站立 |
| **R3** | 从产品自身容器里取出一份 | 已翻开顶盖的纸盒 + 从中抽出的未开条包 | 重新设计 | 抽屉/杯架/柜子属家具不属产品容器，不触发 R3 |
| **R4** | 从快递箱拿 / 箱里有货 | 纸盒（箱内整齐竖放） | 照原片 | — |
| **R5** | 从口袋或小包拿出 | 未开条包 | 照原片 | 符合真实物理尺寸 |
| **R6** | 拧盖、倒出 | 很小：手捏已开封条包；看得清：翻开纸盒顶盖 | 重新设计 | — |
| **R7b** | 很小、在人手边、是镜头主体 | 纸盒（手里或原位） | 照原片 | — |
| **R7** | 很小、在人手边、不是主体 | 手捏已开封条包，始终在手里 | 重新设计 | 中远景偏小不硬放纸盒 |
| **R8** | 很小、没人碰（窗台、背景） | 原位立 1 个纸盒 | 照原片 | — |
| **R9** | 其他看得清的瓶或盒 | 纸盒（手持握两侧、桌上原位立；原片多个也只放 1 个） | 照原片 | — |

## 4. 五段式提示词规范与提交门禁

主流程每段与单镜补做一律采用五段式骨架（主流程由 `plan` + `swap_design.py decide` 生成，单镜补做由 `round open` / `swap_design.py skeleton` 生成）：

| 段落 | 必填内容 |
|---|---|
| `【生成目标】` | 复刻 `@视频1` 的景别切换、环境、人物神态与指定语言台词，将原片中具体竞品逐个完全替换为设计表产品；有纸盒加“并按 `@图片2` 的手掌比例写抓握”（人物卡补做不写 `@视频1`） |
| `【参考素材职责】` | 首次生成写 `@视频1` 职责（含“完全移除原片中的……及字幕”与“产品大小不沿用原片被替换容器大小和手部张开幅度”）；每张上传图单独一行“用于……，不采用……”；人物卡说话镜写 `@音频1` 音色职责 |
| `【主体与关系】` | 光线、场景、人物外貌服装站位、“画面里只有 `<产品>`，原片竞品所在的其他位置是空的”、产品物理句、每个说话人的音色句（非播音腔）；人物卡模式额外写全 3–6 固定物件、轴线锚点与机位表 |
| `【事件脚本】` | 一镜一阶段：`阶段一：<景别机位>。<产品在哪、手怎么动>。大小参照：<具体参照关系>。<说话人>台词（<语气>，用<语言>）：{原词}。结束时<产品和人的终态>。` 第二阶段起以“切至”开头，**只写正向描写** |
| `【保持一致】` | 全程仅 1 盒/1 支；有纸盒加“盒身与手掌比例匹配 `@图片2`”；**产品在每一镜里和人脸、手、身边物件的大小关系都一样，不忽大忽小**；环境/光线/空间方向稳定；听者自然闭口；声音（同 `@视频1` 或“无bgm”）；台词只有上面写出的这些；画面不显示字幕 |

**代码强校验（`generate --prepare-only` / `shot_regen.py prepare` / `round submit`，不过即拒）**：
- 每份上传素材都有单独职责行，不提未上传素材；
- 五段齐全；阶段数等于参考片镜头数；每阶段均有“结束时……”；台词用 `{}` 不用引号；有台词必写“闭口”；
- 正文严禁画幅/时长/分辨率/帧率/秒数/时间戳（`9:16`、`768P`、`720P`、`8秒`、`0-3秒`、`fps`）、镜头号/规则号（`S217`、`R9`）、厘米/毫米数、任何勺子词、音标或斜杠读音、`【事件脚本】` 内画面否定句；
- 严禁旧写法：`"这不是视频编辑"`、`"将@视频1中……更换为……"`、`"动作照@视频1 / 照它"`；
- 必须符合设计表的图、形态、数量、每镜 `大小参照：` 以及非竞品参照要求；
- 纸盒镜头必须同时传 `carton_views,carton_hand` 两张图（绝不单传九视图）；混合形态（盒+条包）按需传 3–4 张。

## 5. 每镜大小参照（首次生成与补做必填）

每个出现我方产品的阶段，在“结束时”之前必须写 `大小参照：……`：
1. 先看原片高清帧：画面有**人脸**先写与人脸比例，再写离产品最近的**手**（手张开幅度）或**实际物件**（杯子、手机、水瓶、手表、书）。
2. **严禁拿竞品或原片容器作参照**（禁止出现“原瓶/滴剂/滴管/胶囊/和原片一样大”等字眼，代码会自动拦截）。
3. 只写肉眼可见的比例关系，**不写厘米数**；前后景深不同时明确说明远近。
4. 首次生成挂 `@视频1` 时，职责句必须保留骨架里的“产品的大小不沿用原片里被替换容器的大小和手的张开幅度，按事件脚本里每一镜写的大小参照来画。”

**快速推算对照表**（真盒 10×13×7 cm、条包约食指长略宽于拇指指腹；**提示词里只写右两列说法**）：

| 参照物 | 纸盒写法 | 条包写法 |
|---|---|---|
| 握持的手 | 拇指在一侧、四指在另一侧，手张开到一整掌宽才包住盒身左右两侧；盒宽比四指并拢手掌略宽，盒高约手掌根到中指尖七成，不是指尖捏着 | 拇指和食指捏住下半截，上半截露在指外；约一根食指长，宽比拇指指腹略宽 |
| 托在掌心 | 盒底盖满整个手掌，四边几乎不露掌心 | 横放掌心，两头与手掌两边差不多齐 |
| 举在脸旁（同距） | 盒高约等于下巴到眉毛，盒宽约两外眼角之间，比整张脸小一圈 | 长约两个嘴宽 |
| 马克杯 | 比马克杯略宽，高出约三分之一 | 与马克杯差不多高，细得多 |
| 竖放手机 | 比手机矮一截，宽得多 | 比手机短三分之一，宽不到一半 |
| 500 ml 矿泉水瓶 | 约瓶身六成高，比瓶身粗 | 约瓶身一半高 |
| 普通玻璃水杯 | 和杯子差不多高 | 比杯子矮 |
| 手表表盘 / 平装书 | 盒宽约两个半表盘；书比盒高出约三分之一 | 比表盘窄；约书高一半多 |

## 6. 穿帮补做：一轮一批 + 默认人物卡模式

**第一次生成（a1）**挂去字幕参考视频；**审片查出穿帮后的每一次补做**一律按**一轮一批**默认走**人物卡模式**（不挂参考视频，彻底摆脱原片竞品轮廓和动作惯性）：

1. **汇总整条片穿帮**：全部段审完后写 `RUN/shots-regen/goofs.json`（每条带 `seg`、`at`、`why` 八类原因、`note`，切点错位时按 strip 补 `"source_s": "起-止"`）。
2. **生成人物卡（整片一次、各轮共用）**：写 `RUN/cards/cast.json`（英文 `identity` 把体重体型量化写最前 + 原服装 + 全片最清正脸 `srcs` 最多 3 张），跑 `shot_regen.py cards build --run RUN`（4:3 2K）。逐张 `read_file` 验收像不像、胖瘦对不对，不对改描述 `--force --only ID` 重出。
3. **开轮（默认人物卡模式）**：`shot_regen.py round open --run RUN --file goofs.json`（自动 `locate` 帧号/镜像/台词/声音方式，写含 `# cards`、`# views`、说话镜 `# voice: A-B` 的五段式骨架；单处参考视频模式 `--mode reference` 仅用户明确点名时用）。
4. **写人物卡五段式**：
   - 环境只用文字，不挂场景图；`【主体与关系】` 必须按序写全：**① 时间与光 → ② 3–6 个固定物件及相对位置 → ③ 轴线锚点（含“左手边/右手边”）→ ④ 各人站位与朝向 → ⑤ 机位表（架哪、拍谁、固定背景是什么）→ ⑥ 产品初态与数量 → ⑦ 说话镜 7 要素音色句**（人种口音、性别年龄、音高、质感、语速节奏、习惯、一句“不是什么”）。
   - 不新加切刀，原片几镜写几阶段并点名机位；每阶段写身体动作与听者闭口具体反应；台词 `{原词}` 后只接动作不接语气；【保持一致】必须含“空间方向稳定”“同一种画面质感”及说话镜“自然闭口”。
   - 易穿帮的递交/抛接可跨镜省略，写成第一帧产品已稳握在接手人掌中。
5. **批量提交与拼回**：
   - `shot_regen.py round submit --run RUN`：全部过检后一次性提交至默认 **100x `100x-minimax-h3`（`standard` / `768P` / `9:16`）**，音频参考随任务直传 100x，下载并生成 `NAME.result.png`。
   - `read_file` 看 `result.png` 与生成 `.mp4`；通过的由 `shot_regen.py round splice --run RUN [--drop 仍有穿帮NAME]` 一次拼回并自动 `select`。
6. **次数上限与缩窄规则**：
   - 同一处（按原片秒数重叠计）最多补做 **3 轮**：第 2 轮必须比第 1 轮更短（如缩到单个动作），第 3 轮不长于之前最窄轮。
   - 3 轮仍未过时不卡死流程，照常 `finish` 并写入交付汇总交用户裁定：破例第 4 次付费（`prepare --again --user-quote "..."`）或本地修复（仅限无说话嘴镜头用同段干净帧 `splice SRC:A-B@N --no-mouth` 放慢填补，或删 ≤0.5 秒坏帧）。

## 7. 声音、定格裁剪、缓存与终检硬门禁

- **说话镜头只用自己的同期声**：画面看得到说话嘴的地方，声音必须是同一文件、同一时刻自带音轨，无论台词是否改动。口型错位直接补做该镜（`lip_sync`）；`--sound source` / `splice --audio-window` 仅允许用在无嘴画面且必须加 `--no-mouth`。
- **段尾不留定格帧（含缓漂静止）**：`media_pipeline.frozen_tail` 同时检测静止帧与相邻帧差 < 0.3 的缓慢漂移。`select`、`round splice`、`finish.py`（第一步 `shot_regen.py retrim --all`）自动裁掉超出原段长的定格补尾，同时保护末尾仍在说话的真实台词不被截断（原片本就静止的片尾卡可 `--keep-frozen-tail`）。
- **去字幕缓存**：`caption_lama.py` 按 512×512 块 + 遮罩 + 模型版本缓存在 `~/.cache/lymphloop-models/lama-cache/`（默认 12 GB 上限，跨 RUN 共享）。时间卡（`DAY 1`、`WEEK TWO` 等）统一清除并在 `captions` 阶段原样贴回。
- **成片按内容缓存**：`recut` 按原子块内容签名缓存于 `RUN/recut/render/atoms/`，`brand` 按块盖水印缓存于 `RUN/recut/brand-atoms/`，`final-screen` 对比 `content.json` 与 `baseline.json` 仅重检变动块或上次遗留问题块。
- **水印模板与固定位置**：`watermark scan` 优先匹配 `assets/watermarks/<目标词>-fixed.*` 笔画模板；非模板片先聚类出固定位置（`positions`）再补扫，且过滤产品印刷标签误报。`brand` 全片每处使用固定框与固定读向覆盖白色 `LYMPHLOOP`，不忽大忽小、不整片常驻。
- **杜绝竞品闪回**：`plan` 自动将段边界向外吸附到逐帧切点并合并 ≤0.5 秒碎镜头；`final-screen` 对接缝、拼接点与 ≤0.5 秒碎镜头输出闪回帧板，Agent 逐张 `read_file` 看完后 `swap.py flashback-review --clean`。
- **纸盒量尺 + 产品帧板双关**：`select` 自动跑 `carton_check.py`（正面高:宽 ≤ 1.65，外形长:短 ≤ 2.3，不竖立露窄侧面）；`final-screen` 输出产品原尺寸帧板，Agent 逐张 `read_file` 看完后 `swap.py product-review --clean`。两项复核均完成才允许 `finish.py` 出看板交付。
- **跨 RUN 共用结果**：同母版改版片在代表片完成终检后跑 `swap.py reuse --from 代表片RUN`，零生成费复用代表片选片；代表片若后续修改（`retrim` / 补做），对共用片重跑 `reuse` + `finish` 同步。
- **听写静音幻听过滤**：所有听写统一过滤 `no_speech ≥ 0.4` 且 `avg_logprob ≤ -0.8` 的 Whisper 静音幻听句；`plan/words/G##.json` 绑定 `G##.range.json`，切段范围变化时自动重听。
