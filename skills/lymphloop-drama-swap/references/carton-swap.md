# 换纸盒的段落：五段式写法（用户 2026-11-20 定）

用户 2026-11-20：“如果是要换纸盒的段落可以用我这套方法，其他关于盒装的参考图都可以移除掉，没什么用了。”这套方法来自用户在 Gemini 里用 clone-seedance-video skill 写的提示词，测试片 2412 的 G05（06:01 起四镜，6 秒）和 G16（储物柜前拿盒 + 举盒特写，4 秒）都**一次成功**；之前我们按旧规则（只写正向、放慢单镜头、各种纸盒图）同样几个镜头试了 3–4 轮都失败（原样照搬竞品盒、盒顶留竞品叶子标、两个盒子）。原文存在测试 RUN 的 `shots-regen/gemini-user-prompts/`，下面第 5 节摘了一段。

**什么时候用**：段落里要把竞品换成**纸盒**（立在桌上、拿在手里、拿起放下、转着看）。2026-11-20 起主流程每段（包括条包段、旁白段）都用同样的五段式，规则和检查见 [rules-now.md](rules-now.md)；本页是纸盒段的两张图、模型和范例。主流程里 `plan` + `swap_design.py decide` 直接写出骨架，`generate` 和其他段一样交给 APIMART seedance-2.0；下面第 4 节是单镜头重生成的做法。

## 1. 素材（只有这三样）

- `@视频1`：原片这一组镜头，**原速、多镜头连在一起**（G05 一次四镜、G16 一次两镜），带原声。用 `shot_regen.py ref --frames A-B` 取一段连续帧（4 秒以上原速保留原声；只有孤立的、不到 4 秒的单镜头才放慢）。参考片照常去字幕去水印，竞品留着不抹。
- `@图片1` = `carton_views`（`assets/product/carton-views.jpg`）：同一个纸盒白底九个角度。
- `@图片2` = `carton_hand`（`assets/product/carton-hand-scale.jpg`）：一只真手拿着纸盒正面，**只管纸盒和手的比例、握法**。2026-11-20 换成用户去掉地毯背景的版本（浅灰纯色背景）：原图的地毯曾被模型当成纸盒特写的背景搬进画面。
- 纸盒段的 `# views:` 一律是 `carton_views,carton_hand`。别的纸盒图都已移除（拼图、正面单图、顶面图，备份在 `~/.codex/skills-backup/lymphloop-swap-claude-carton-2026-11-20/`）。

## 2. 生成

- 用户 11-20 在 100x 上用 seedance-2.0 720P 参考视频生成跑通了 G05/G16。skill 里一律走 **APIMART `seedance-2.0`**（用户 2026-11-20："我们先采用APIMART中的seedance-2.0，不要默认采用100x"；画幅固定 9:16、时长按目标段、分辨率固定 720P，全部走接口参数，提示词里不写）：`size: 9:16`、`resolution: 720p`、`duration` = 段长向上取整（4–15 秒）。100x 只在用户点名时用（`shot_regen.py prepare --channel x100`）。
- 画幅、时长、分辨率都是参数，提示词里不写“竖版 9:16”、不写秒数。
- 输出 720×1280；拼回时 `swap.py splice` 会缩到段的尺寸。

## 3. 五段式模板

```text
【生成目标】
复刻@视频1的<几个镜头的景别切换>、<环境>、<人物神态>与<语言>台词，将<原片里竞品的颜色样子和位置，有几个写几个>完全替换为1盒yesnap LymphLoop青绿色纸盒，并按@图片2的手掌比例将抓握动作改为<单手包握盒身两侧拿起 / 立在桌上>。

【参考素材职责】
@视频1用于复刻<人物长相服装>、<陈设>、<镜头切换机位与时机>和说话口型节奏，完全移除原片中的<竞品，逐个写>及字幕。
@图片1用于提取单个yesnap LymphLoop青绿色竖长纸盒的<三维外观、颜色、正面标签、侧面竖排标志、顶盖>，不采用九宫格多视图版式和白底。
@图片2仅用于锁定单个纸盒相对成年人手掌的真实尺寸比例（盒宽撑满虎口）及手指包握盒身左右两侧的抓握方式，不采用图中的手与浅灰色背景。

【主体与关系】
<光线、场景、背景里看得见的东西>。<人物：年龄、族裔、发型、衣服、坐姿/站位>。<纸盒在哪：仅底面着地稳立1盒青绿色LymphLoop纸盒，正面朝向谁；原片其他竞品的位置写明是空的>。纸盒与人物、桌面同一种写实画面质感，直角硬挺不变形。音色——<说话人1>：<年龄>拉丁裔男声，<音色>，<语气>，不是播音腔；<说话人2>：……

【事件脚本】
阶段一：<景别和机位（谁的过肩、拍谁）>。<纸盒在哪>，<谁做什么>，<说话人>台词（<语气>，用<语言>）：{<原词，一字不改>} <听者>自然闭口聆听。结束时<纸盒和人的终态>。
阶段二：切至<景别>。……
（一个镜头一个阶段；拿起盒子的那一拍写“伸出<哪只手>，虎口张开按@图片2比例五指包握住纸盒左右两侧直角边”；有纸盒的阶段在“结束时”前写一句“大小参照：……”，用这一镜里的手、脸或身边物件说清纸盒多大（用户 2026-11-25，rules-now.md“每镜大小参照”）；每阶段以“结束时……”收尾。）

【保持一致】
全程仅1盒青绿色纸盒，盒身尺寸与手掌比例严格匹配@图片2，硬挺无挤压变形；人物面容服装、<道具>、空间方向与光线同@视频1一致；听者自然闭口聆听；无bgm，只保留环境声、动作声和<语言>台词；画面不显示字幕。
```

要点（和旧规则不同的地方）：

1. **明确移除**：在【参考素材职责】里写“完全移除原片中的<竞品>”，在【生成目标】写“完全替换为1盒”。这一类“移除 / 不采用 / 无 / 仅”的写法在【参考素材职责】【主体与关系】【保持一致】里允许（`prepare` 的否定句检查对五段式只查【事件脚本】）。
2. **比例靠图2和“盒宽撑满虎口”**，不写厘米，也不再写一长串“高约为宽的一倍三”。
3. **按镜头分阶段，不写逐秒时间戳**；每阶段一句景别机位、一句产品在哪/手怎么握、一句台词、一句“结束时”。
4. **数量写两遍**：【主体与关系】“仅1盒”，【保持一致】“全程仅1盒”；原片有两个盒子时写“无第二个盒子”。
5. **台词**：`{原词}` 一字不改，带语气和语言；每个说话人一句音色；不说话的人写“自然闭口”。
6. **不写**“请注意这不是视频编辑”、“将@视频1中……更换为……”这类旧句式，也不写“竖版 9:16”、秒数、时间戳、分辨率。

【参考素材职责】
@视频1用于复刻微胖拉丁裔老年男性的面容、花白短发与胡茬、红黑格纹衬衫内搭白T恤（领口挂金属框眼镜）、休息室灰色铁皮储物柜背景、两镜头切换时机及说话口型语气，完全移除原片中的2个绿白窄盒与黄白字幕。

【主体与关系】
白天室内柔和日光灯，员工休息室灰色铁皮储物柜在背景，前景木桌边坐着六十岁左右微胖拉丁裔男子（红黑格纹法兰绒衬衫、白T恤领口挂眼镜）；第1镜左前景有站立同事的深色外套肩部遮挡形成过肩构图。木桌面上仅底面着地稳立1盒青绿色LymphLoop纸盒（无第二个盒子），盒身硬挺直角不变形，尺寸比例严格匹配@图片2，与人物和桌面同一种写实画面质感。音色——红黑格子衬衫男子：六十岁左右拉丁裔男声，中低音粗粝略沙哑，带强烈怀疑与嫌弃反问语气，不是播音腔。
