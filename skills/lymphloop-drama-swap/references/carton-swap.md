# 纸盒换品专项指南（五段式 + 100x H3 + 数字量尺）

涉及纸盒的镜头（规则表命中 `carton`，含手持展示、桌上静置、开盖抽包、快递箱成箱）统一使用本指南的**双图 + 五段式 + 每镜大小参照 + 数字量尺**标准。默认生成渠道为 **100x `100x-minimax-h3`（`standard` / `768P` / `9:16`）**。

---

## 1. 参考图必传规则（双图缺一不可）

- **两张纸盒图必须一起给，顺序固定**：`# views: carton_views,carton_hand`
  - `carton_views`（`assets/product/carton-views.png`）：九视图，负责正面/顶面/侧面外观、青绿配色、大字 `LYMPHATIC`、`yesnap` 与 `LymphLoop` 标志。
  - `carton_hand`（`assets/product/carton-hand-scale.jpg`，已去地毯背景）：成年人单手握持实拍，负责真实手掌比例（盒宽撑满虎口、拇指与四指分握盒身左右两侧）。
- **只传九视图不传手持图会导致比例严重走样**（又细又高、缩成火柴盒），`generate --prepare-only` 与 `shot_regen.py prepare` 会直接拒绝单图纸盒任务。
- 若同一段同时出现纸盒和条包，纸盒两张图排在前面，后面接 `handheld_photo`（未开条包）和/或 `opened_packet_hand`（已开条包），按需 3–4 张一起传。

---

## 2. 纸盒物理与比例要点

- **真实尺寸（仅作推算，提示词里绝不写厘米数）**：宽 10 × 高 13 × 厚 7 cm（正面高:宽 ≈ 1.3，侧面高:宽 ≈ 1.86，顶面 ≈ 1.43）。
- **宽正面朝镜头**：印有 `LYMPHATIC DRAINAGE SUPPORT` 的宽面是正面；竖着展示或放台面时必须明确写清“正面（印 LYMPHATIC 的宽面）朝向镜头”，绝不能让窄侧面（竖排手写 LymphLoop 标志那一面）冒充正面。
- **翻盖方向**：铰链在正面顶边，手指从背面顶边抬起，顶盖向正面方向整片翻起，露出盒内竖直密排的青绿色条包。
- **每镜必写大小参照**：绝不拿原片竞品瓶/盒作参照；优先对照当下镜头里的**人脸**（举在脸旁：盒高约下巴到眉毛、盒宽约两外眼角之间）、**握持的手**（手张开到一整掌宽、拇指和四指分握左右两侧，不是指尖捏着）以及**近旁真实物件**（比马克杯略宽且高出约三分之一、比竖放手机矮一截但宽得多）。完整对照表见 [rules-now.md](rules-now.md)。

## 3. 五段式结构与完整示例

五段式统一用于首轮原片参考生成与单镜补做，正文严禁出现画幅、分辨率、时长、秒数、时间戳、镜头号、规则号、厘米数、勺子词、画面否定句，以及旧写法 `"将@视频1中…更换为…"` / `"这不是视频编辑"` / `"动作照@视频1"`。

```text
# views: carton_views,carton_hand

【生成目标】
复刻@视频1的景别切换、办公室环境、人物神态与用英语说的台词，将原片中的深绿色滴剂纸盒与琥珀色滴管瓶完全替换为@图片1所示的yesnap LymphLoop外包装纸盒，并按@图片2的手掌比例写抓握。

【参考素材职责】
@视频1用于复刻人物外貌、服装、办公桌陈设、镜头切换机位与时机和说话口型节奏，完全移除原片中的深绿色滴剂纸盒与琥珀色滴管瓶及字幕；产品的大小不沿用原片里被替换容器的大小和手的张开幅度，按事件脚本里每一镜写的大小参照来画。
@图片1用于yesnap LymphLoop纸盒的外观，青绿色硬纸盒、直角直边、正面印yesnap标志与LYMPHATIC大字，不采用其背景。
@图片2用于yesnap LymphLoop纸盒在成年人手中的真实比例与单手握持两侧的姿势，盒宽撑满虎口，不采用其人物与背景。

【主体与关系】
办公室白天自然光，木质办公桌上有笔记本电脑、马克杯和几张文件。画面里有两位成年男性，穿浅蓝衬衫的男子坐在桌后，穿深灰卫衣的同事站在桌旁。画面里只有1个yesnap LymphLoop纸盒，原片竞品所在的其他位置是空的。纸盒是硬质直角直边纸盒，正面印有LYMPHATIC大字。穿浅蓝衬衫的男子用自然美式英语说话，中年男声，中低音，带一点松弛沙哑，语速平稳，不是播音腔。

【事件脚本】
阶段一：近景平拍，穿浅蓝衬衫的男子坐在办公桌后，右手拇指与四指张开到一整掌宽握住1个yesnap LymphLoop闭盒的左右两侧，印有LYMPHATIC的宽正面正对镜头。大小参照：纸盒比他的手掌略宽，盒高约等于他下巴到眉毛的距离，比桌上的马克杯略宽且高出约三分之一。穿浅蓝衬衫的男子台词（诚恳自然，用英语）：{This is Yesnap LymphLoop, it made a real difference for me.}。结束时他仍单手握着这1个纸盒正面朝镜头。
阶段二：切至过肩中景，穿深灰卫衣的同事倾身看过来，闭口认真聆听，穿浅蓝衬衫的男子将同一只纸盒稳稳立在木质办公桌面上，底面完全贴合桌面，宽正面朝向两人之间。大小参照：立在桌上的纸盒比旁边马克杯略宽、高出约三分之一，与上一镜手里的纸盒大小一致。结束时桌上只有这1个立着的纸盒，两位男子自然看向盒子。

【保持一致】
全程画面里只有1个yesnap LymphLoop纸盒，无其他产品或瓶子；纸盒宽正面始终清晰可见，盒身与手掌比例匹配@图片2；产品在每一镜里和人脸、手、身边物件的大小关系都一样，不忽大忽小；人物面容服装、办公室陈设、空间方向、光线同@视频1；听者自然闭口聆听；背景音乐和环境声同@视频1；台词只有上面写出的这些；画面不显示字幕。
```

## 4. 纸盒出现穿帮时的补做（默认人物卡模式）

原片参考生成如果把纸盒画成细长条、把窄侧面立成正面、或在多镜切换中忽大忽小，**直接进入第 10c 步人物卡补做**（默认仍走 `100x-minimax-h3` / `standard` / `768P`）：
1. 不挂 `@视频1`，只挂 `# cards:`（人物卡）+ `# views: carton_views,carton_hand` +（若说话）`# voice: A-B`；
2. 用文字写全光线、3–6 个固定物件、轴线锚点、机位表与固定背景；
3. 在事件脚本里明确写死纸盒初态（例如从第一帧起就稳握在接手人掌中，避免抛接或翻手遮挡），并写清宽正面朝向与每镜大小参照；
4. 跑 `shot_regen.py round submit` → `read_file` 看 `result.png` 与生成 `.mp4` → `round splice`。

## 5. 纸盒自动尺子与产品帧板复核

- **`select` 自动量尺（`scripts/carton_check.py`）**：对含纸盒图的段按每 0.25 秒抽帧，本地量像素与 OCR 检测 `LYMPHATIC`。只要满足以下任一条就会拦截并生成“整帧 / 生成盒放大 / 同高真盒”三栏并排对照图：
  - 正面高:宽 > **1.65**（真盒 1.3，宽容四分之一以内）；
  - 任意一面外形长:短 > **2.3**（真盒侧面 1.86）；
  - 纸盒竖立 ≥ 0.5 秒却始终看不到 `LYMPHATIC` 正面（只见窄侧面手写标志）。
- 被拦截后，Agent 必须用 `read_file` 打开并排对照图：确认真变形/窄侧面则写进 `goofs.json` 补做；确系开盖、遮挡或虚焦误量，才加 `--carton-ok "看过：原因"` 放行。
- **终检产品帧板（`product_sheets`）**：`final-screen` 还会对所有纸盒段按原尺寸每秒 3 帧裁出产品帧板，Agent 必须逐张 `read_file` 复查（防止手挡、远景、运动模糊躲过量尺），复核后执行 `swap.py product-review --run RUN --clean`（或 `--hit "秒-秒:说明"` 进入补做）。
