# 生成片审片清单（Antigravity 原生看听 + 像素量尺 + 穿帮补做）

审片核心原则：**重点只抓穿帮，比例看数字尺子，查出穿帮一律按一轮一批走人物卡模式定点补做**（同一处最多 3 轮）。

---

## 1. 八类穿帮清单（补做登记原因 `why`）

凡命中以下任意一类，都属于**穿帮**，必须记入 `goofs.json` 走 `shot_regen.py round open` 补做（补满 3 轮仍未过才如实写入交付说明由用户裁定）：

| 编号 | `why` 代码 | 穿帮判定标准 |
|---|---|---|
| 1 | `competitor` | 竞品仍在：容器、滴管、胶囊/软糖/粉末、旧标签、品牌字，哪怕很小、在背景、只闪几帧，或在接缝/拼接点闪回 |
| 2 | `count` | 产品数量不对，或镜头中途凭空出现、消失、莫名变成别的东西 |
| 3 | `shape` | 形态或大小明显错：纸盒像瓶子/名片/火柴盒/鞋盒/扁砖、弯折融化；条包变硬棍或被整支吞下；**纸盒正面高:宽 > 1.65 或任意外形长:短 > 2.3**；**产品大小与当下镜头里的手、脸、身边物件明显对不上，或同段前后镜头忽大忽小** |
| 4 | `side` | 展示/静置镜头拿窄侧面或背面当正面：纸盒竖着站在画面里超过 0.5 秒却看不到 `LYMPHATIC` 宽正面、只看到竖排手写 `LymphLoop` 标志那一面 |
| 5 | `physics` | 物理上做不到：条包无支撑自己竖立、画面里出现撕条包、服用镜头手里没拿条包或张嘴伸舌滴服/咀嚼 |
| 6 | `identity` | 人物、脸、衣服、场景或机位明显换掉，与前后原片镜头接不上 |
| 7 | `speech` | 改过的台词没说出来、吞音/乱码、说出竞品品牌名或我方没有的成分，或可见嘴部与同期声明显对不上（口型错位） |
| 8 | `text` | 画面残留多余字幕、竞品水印或异常大段错乱叠加字 |

---

## 2. 不算穿帮、也不触发补做的情况

- 纸盒高宽比在数字红线以内（正面高:宽 ≤ 1.65、外形长:短 ≤ 2.3），且与手/脸/身边物件大小协调；
- 纸盒略微后倾露出顶面，但正面比例仍在 1.65 以内；镜头透视带来的轻微梯形；盒子被手自然挡住一部分；
- 包装上的**极小字体**（成分表小字、`DRAINAGE SUPPORT`、净含量等）模糊或乱码——只要大字 `LYMPHATIC`、`yesnap`、`LymphLoop` 标志和主色正确即可；
- 轻微动作僵硬、手指边缘轻微虚焦、嘴角微湿；
- 整段保持一致的左右镜像。

## 3. 每段必做的原生看听与 6 项结构化自检（`select --audit`）

1. **直接看动图 + 听真声**：对每段生成片 `RUN/generation/results/<job>-c1.mp4`，**必须直接用 `read_file` 看并听完整视频**（不只看 2 fps 静态帧板 `RUN/qa/<job>-c1.png`），同时核对 `swap.py review` 输出的本地 `faster-whisper` 逐词校验（`words`）、残留字幕（`captions`）与叠加文字（`overlay`）报告。
2. **提交 6 项 `--audit` 核查**：
   - `competitor_clean`：无竞品容器、滴管、标签、品牌词残留
   - `front_face_ok`：展示/近景为 `LYMPHATIC` 宽正面朝镜头，无竖立仅露窄侧面超过 0.5 秒
   - `scale_ok`：符合纸盒数字尺子（正面 ≤ 1.65，外形 ≤ 2.3）且与当前镜头里的手/脸/物件大小一致、前后不忽大忽小
   - `physics_ok`：条包不自站立、不撕包、服用时手中有已开条包并闭唇轻抿
   - `speech_lip_ok`：已亲耳听过生成音轨，台词完整准确、无竞品词/乱码、口型与声音同步
   - `text_clean`：无多余字幕、竞品水印或错乱叠加文字
3. **自动拦截与补做**：
   - `--audit` 任一项为 `false` 时，`select` 会自动拦截并要求记入 `goofs.json` 走 `shot_regen.py round open` 人物卡补做（仅在已达 3 轮上限需带瑕疵交付记录时使用 `--allow-audit-fail`）。
   - `select` 会自动处理：残留字幕清理（`*.decaptioned.mp4`）、段尾静帧/缓漂定格自动裁剪（`frozen_tail`，同时自动保护末尾正在收尾的真实说话不截断）、以及纸盒 `carton_check.py` 自动尺子检测。

## 4. 纸盒数字尺子与终检产品帧板（双保险）

1. **像素量尺（`scripts/carton_check.py`，`select` 自动运行）**
   - 原因：缩略图和抽帧视频极易让肉眼忽略纸盒被拉高 40%–50% 或竖着只露窄侧面。
   - 机制：每 0.25 秒抽帧本地测量像素比例并 OCR 检测 `LYMPHATIC`。一旦超线即生成三栏并排对照图（左：原帧与量框；中：生成盒放大；右：同高真盒）并拒绝 `select`。
   - 处置：Agent 必须先用 `read_file` 打开并排对照图。确属变形/侧面 → 填 `scale_ok=0` 或 `front_face_ok=0` 并进 `goofs.json` 补做；确属开盖/遮挡/虚焦误量 → 加 `--carton-ok "看过：原因"` 放行。
   - 批次复查可用：`"$PY" scripts/carton_check.py batch 批次目录` 生成汇总 `carton_audit.md`。

2. **产品原尺寸裁切帧板（`final-screen` 自动产出 `product_sheets`）**
   - 原因：量尺可能漏掉被手挡住、体量较小或快速运动中的纸盒。
   - 机制：`final-screen` 会对每个含纸盒图的生成段按原尺寸每秒 3 帧裁出产品帧板（`final/<sha>/product/`）。
   - 处置：Agent 必须用 `read_file` 逐张看完，确认无瘦高盒、薄卡片、窄侧面立着或条包自站立后，运行：
     ```bash
     "$PY" scripts/swap.py product-review --run RUN --clean
     ```
     若发现穿帮，则 `--hit "秒-秒:看到了什么"` 登记并进入人物卡补做；**补做后同一段必须整段重看产品帧板**。`finish.py` 在未完成 `flashback-review` 和 `product-review`（或仍有未修 hit）时会拒绝交付（除非用户明确同意带瑕疵交付并传 `--user-accepted "用户原话"`）。

## 5. 声音、本地修补边界与选片记录

- **声音归属**：画面中可见人说话的镜头一律使用同一文件、同一时刻自带音轨；口型对不上属 `speech` 穿帮，直接补做该镜（`lip_sync`），不做本地贴音或口型对齐。`--sound source` / `splice --audio-window` 仅允许用在无说话嘴的画面（必须加 `--no-mouth`）。
- **允许的免费本地修补**：`--clip-in/--clip-out` 裁掉补尾与 ≤0.5 秒坏闪帧；`select` 自动去残留字幕；`splice` 借同素材兄弟片整镜或用同段干净帧放慢填补无嘴镜头（上限瑕疵兜底）；`region_inpaint.py :purple`（字幕）与 `:ink`（道具印刷文字）。**严禁对生成画面内产品穿帮做贴图、抹除、放大裁切或擅删原片内容**（见 [controlled-edit.md](controlled-edit.md#6-审片与禁止贴图红线)）。
- **`select --note` 记录**：简明写明 6 项核查结论、实际片长、`clip_in/out` 依据、首尾句是否完整及任何已处理/待补瑕疵，作为交付说明来源。
